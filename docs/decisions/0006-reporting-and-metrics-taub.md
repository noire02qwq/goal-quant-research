# 0006：汇报与测评口径——指标第四维排名稳定性 τ_b 与宣称强度分档

> 状态：**已采纳**（2026-11-11 @dev 双轮核验 PASS：τ_b 逐位复算 + 决策 1–4 笔记/论文双层回源 + F1/F2 修正复扫通过） ｜ 日期：2026-11-11 ｜ 作者：@research ｜ 关联：[literature/W5-real-eval-fault-style.md](../literature/W5-real-eval-fault-style.md)、`research-demos/w5-fault-drill-demo`（`992a2aa`+`d4ef01c`）、brief-plan §6.1

## 背景

W5 文献线（8 篇全文精读）对既有四条结论的判定中，三条直接指向汇报与测评口径：**C 修正②**要求给指标加第四维排名稳定性（Execution 论文：换成交假设高波压缩板 Kendall τ_b=0.21，5 个 LLM 策略名次上移 2–7 位系执行伪影）；**A 修正③**要求执行假设显式披露 + 至少一档敏感性重跑报 τ_b；**B** 要求宣称与证据同档（The Alpha Illusion 表 2 的「宣称强度→所需协议→可用措辞」四档表为直接来源，AllPath「明文不报账户收益」为同口径先例）。W5 demo 已补第 7 步实测（`d4ef01c`）：两档执行假设下三策略排名完全一致，与 Execution 的排名翻转形成正反成对证据——本记录把三条文献判定与该实测收口为可执行口径。

## 决策

1. **`GoalEvaluation.metrics` 增列排名稳定性**：新增 `rank_stability_tau`（Kendall τ_b，成对比较：基准执行档 vs 压力执行档）与 `exec_tier` 披露字段（档位参数、简化合并口径必须随输出同报）。任何对外汇报的策略排序表须附 τ_b，缺 τ_b 的排序表不得出报告。文献第四维的另一件 **top-3 Jaccard 作扩展位暂不纳入**（源文 τ_b 与 Jaccard 并列，此处半采纳留痕），留报告模板定稿时评估。
2. **汇报口径按宣称强度四档收口**：源文四档 = ①historical backtest ②prototype ③deployable claim ④autonomous trading ability。Phase 1 演示**只允许第 1–2 档措辞**（历史回测 / 原型：本窗口正收益轨迹，无部署语言）与「流程可靠+证据完整」的流程性表述；**禁止第 3/4 档**（「可部署 alpha」「自主交易能力」「跑赢市场」）。档位晋升须先过对应协议（Alpha Illusion P1–P6 的相应项）。
3. **成本维度自补**：`cost_drag` 为必报项，口径写「**凡报收益必同报回撤与成本**」；边界情形按 AllPath——不报收益时改用 operational 指标，不得省略回撤与成本而单报收益。
4. **测评报告三件套**：每份报告必须写明**固定窗口、执行档位、敏感性重跑 τ_b**，三者缺一不得出报告（对应 A 修正③）。

## 理由

- 排名会因执行假设翻转是实证（Execution），单报收益/胜率会把执行伪影当能力；Strat-LLM 的高胜率陷阱独立佐证「胜率不可单独当稳健性代理」。
- τ_b=+1.0 **只证明「假设披露后排序稳定性可报」，不证明策略优**——与 Execution τ_b=0.21 反面成对引用；n=3、两档、单窗口的证据强度上限已写入备选表。
- 宣称分档把结论 B 从口号变成可核查的措辞纪律（Alpha Illusion 表 2；Crypto 实盘 4/4 负 alpha 为基准事实）。
- 成本维度必须自补：LTB/AMA/Strat-LLM 三篇均无成本指标（LTB 自认未计成本会高估收益），不能引为据；Alpha Illusion 的 gross→net 恒等式（35/40 摩擦未建模）是唯一文献依据。

## 备选方案（不采纳的）

| 备选 | 不采纳理由 |
|---|---|
| 单报收益/胜率排序 | Execution 证明排名对执行假设敏感；Strat-LLM 高胜率陷阱（WR 66.67% 的 TR 反低于 WR 54.55%） |
| 把 τ_b=+1.0 当策略质量证据 | n=3、两档、单窗口，只支持「可报稳定性」不支持「策略好」；违反 B 档纪律 |
| 汇报直接用「跑赢/alpha」措辞 | Crypto 实盘无人跑赢（4/4 负 alpha）；Alpha Illusion 第 3/4 档需 P1–P6 全过，本项目未过 |
| 引 LTB/AMA/Strat-LLM 作成本维度依据 | 三篇均无成本指标；LTB 明文承认未计成本会高估收益 |
