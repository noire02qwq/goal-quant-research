# 0007：自进化第一版定位 L2 脚手架级与 L3+ 边界

> 状态：**提议**（待 @dev 双轮核验） ｜ 日期：2026-11-18 ｜ 作者：@research ｜ 关联：[literature/W6-self-evolution-rsi.md](../literature/W6-self-evolution-rsi.md)、brief-plan §12.1 S1 行、harness-hub `docs/design/strategy-lab-goal-strategy-prd.md`（Non-Goals 与 US6/US7）

## 背景

W6 自进化/RSI 专题（@user 点名，11 篇与仓内零重叠）首次给「自进化第一版」补上文献定位框架：**Diving survey 的 L0–L4 分级**（L0 输出级 → L1 模型级 → L2 脚手架级 → L3 改进器级 → L4 判据级；RSI 结构性起点在 L3——改写自身改进机制）；**持续进化遗忘实证**（2611.03219：SWE-Bench 94.0% 经五轮 harness 进化跌至 32.0%，2611.07624 互证「得新失旧」普遍且可靠性增益常伴部署成本上升）；**验证层级**（2607.07663：形式验证器＞执行反馈＞learned judge＞内在信号，已证明的自改进强度沿层级分布；Mirror Loop 实验——无外部反馈的十轮自评信息量 −55%，第三轮插入一次外部验证即恢复前进）；**Resolution Hypothesis**（2611.23068：进化瓶颈在可靠识别改进而非提出改进，候选选择≈抛硬币、误差逐轮复利、大增益多为评测捷径）。

## 决策

1. **自进化第一版 = L2 脚手架级定位明文化**：我们的可进化面限于上下文/记忆（memory_lifecycle 蒸馏）、计划（goal_update_plan v2）、目标改写（goal_changed）——对应 Diving survey L2（脚手架级）；该定位写入设计文档与 PRD 引用处。
2. **L3+（自改写改进器、改判据）= Phase2+ 另立 PRD**：与 harness-hub PRD Non-Goals「多轮自主优化循环留 Phase2」边界一致，本决策把该边界从工程约定升级为**有分级框架与遗忘实证背书的文献级口径**。
3. **验证层级双出口不改**：报告门（机器强制 τ_b/回撤/成本/宣称档，0006）= 执行反馈档（第二级，高于 learned judge）；审批（IN5 人判）= 研究方向判断留在环外——「机器门 + 人判应用」与 2607.07663 层级同构，维持。
4. **单轮、走查式、经审批、可回滚的保守迭代口径维持**：2611.03219 的 94→32 与 2611.07624 的得新失旧是直接实证——`code_version` 版本链可回滚 + 既有用例零红 + 应用走审批的现行纪律获得背书。
5. **US7 对比区分辨率提示列入 v1.1 排期**：迭代对比固定展示两版差值与（若可得）多样本方差提示，**禁以单跑差异宣称改进**（2611.23068：真差异低于评测分辨率时选择退化随机）；落点 harness-hub PRD §5 v1.1 行。

自进化面的「打分」与 0006 同一判分链（四件：报告门四校验、kendall τ_b 重算、指标计算、**`static_scan+validate_contract` 代码双检**）：**固定程序判分（回测指标/回归清单 diff/τ_b 门）+ 人工终审（0005 采纳必须人点）**，LLM 不任裁判（纯自评 −55% 实证 2607.07663）；评分面只读、无 agent 写入口，任何评估器改动走决策记录留痕。与本决策「外部锚声明」互为表里：**锚是程序算的，不是模型说的**。
