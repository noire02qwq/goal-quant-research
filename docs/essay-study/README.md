# 论文 / 文章精读笔记

存放**非每周检索式产出**的深读材料：经典论文精读、方法论文章、外部项目源码走读笔记等。

- 与 `../literature/` 的区别：literature/ 是"按周检索 → 笔记"的产出；这里是主动深读某篇论文/文章的笔记（如 Bailey & López de Prado 的 DSR/PBO 原文、RD-Agent 源码走读）。
- 命名：`<作者或论文短名>-<年份>.md`，例：`bailey-dsr-2014.md`、`rd-agent-walkthrough-2025.md`。
- 必须标注精读范围（全文/部分章节）；引用他人结论时附原文页码或章节号。
