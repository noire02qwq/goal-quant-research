## 命名

## 归档要求

1. 使用 [../templates/literature-note.md](../templates/literature-note.md) 模板。
2. 必含四段：检索式与日期 / 入选论文 / 方向结论 / 对 brief-plan.md 的修订。
3. 仅读摘要的论文标注"仅摘要级"，不得作为已验证结论引用。
4. 方向结论若推翻设计假设，必须同步修订 brief-plan.md 并补决策记录。
