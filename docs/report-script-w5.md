## 3. 逐句剧本（台词 → 操作 → 预期输出 → 对应研究结论）

### 场景 A：提交目标与审批（约 3 分钟）

1. **台词**：「现在提交一个 T2 ETF 动量轮动目标：一句话描述+回撤约束，看系统如何拆解成计划。」
   **操作**：提交 T2 目标（一句话+约束）→ 展示计划 v1。
   **预期**：计划拆解为 任务 DAG（目标→指标→拆解→执行计划，§1 需求①）。
   **口径**：此阶段无收益数字，不做任何效果表述。
2. **台词**：「计划需要审批——**金融动作的批准方必须是人**，agent 不能自批。」（0005 强口径，W4 实证）
   **操作**：审批计划 v1 → 进入执行。
   **预期**：审批记录含 use-time 绑定要素（action identity + material arguments digest）。

### 场景 B：代码生成与历史回测（约 5 分钟）

3. **台词**：「智能体编写回测代码。注意这个接口层：**数据只暴露到当前 bar**，越界读直接抛 `LookaheadViolation`——前视在构造上不可表达，不靠自觉。」
   **操作**：生成代码 → 运行回测。
   **预期**：回测报告产出（IN1：干净回测零越界；可选展示泄露预言机 536% 被拦截）。
   **口径（第 1 档）**：「这是**历史回测**：<窗口> 内收益 <X>%、回撤 <Y>%、成本 <Z>（三同报）。」
4. **台词**：「这一页报告的三件套：固定窗口 <起–止>、执行档位 A（3bp）/B（25bp）、敏感性重跑排名一致性 **τ_b=+1.0000**——换成交假设，三个策略的名次没有变。」
   **操作**：展示报告模板三件套栏 + `demo.py taub` 现场复算。
   **预期**：τ_b=+1.0000（n=3，仅此两档此窗口，不外传）。
   **对照句（反面）**：「公开文献里换假设会翻车：Execution 论文 τ_b=0.21、名次动 2–7 位——所以我们把 τ_b 设为**缺了不出报告**。」（0006 决策 1）

### 场景 C：定时任务与模拟盘前向跟踪（约 4 分钟）

5. **台词**：「创建每周五调仓定时任务——交易日调度+任务依赖+恢复扫描。」
   **操作**：建任务 → 展示调度与 3 期模拟盘交付。
   **预期**：周期任务持续交付 3 期（§1 需求③④）。
   **口径（第 2 档）**：「这是**原型**的模拟盘前向跟踪，t→t+1 口径、成交假设已披露；它验证的是**流程可靠**，不构成收益证明。」（W5 结论①⑦：前向优于回测但不宣称）

### 场景 D：故障注入（约 6 分钟，对应汇报场景「失败修复/重启恢复/改目标」）

6. **台词**：「故障注入三连——先改坏代码。」→ **操作**：注入①。**预期**：修复任务入队、仅故障步重试（`executed={'fetch':1,'backtest':2,'report':1}`）。
7. **台词**：「重启服务。」→ **操作**：注入②。**预期**：回执命中重放 2 次、fetch/signal 零重跑（0002 首写胜出）。
8. **台词**：「用户把回撤容忍从 15% 改到 10%。」→ **操作**：注入③改目标 v2。**预期**：`goal_changed` 入审计、余下按新目标继续（对应 §9 第一次汇报剧本「重规划 v2 并审批」）。
9. **台词**：「还有两类 W5 新增演练：界面诚实与数据面。」→ **操作**：注入④⑤。**预期**：submitted≠filled 对账点名 + 熔断 6%>3% 真触发；污染/干净**回测签名逐字节相等** + 摄取拦截 admit=False（IN6：interface 诚实 / 数据面正交性）。
10. **台词**：「最后是数据固定化：seed=20261111，两次运行签名一致——演示数据不翻车是设计出来的。」**预期**：sha256 一致。

### 场景 E：收尾报告与边界声明（约 3 分钟）

11. **台词**：「总结这轮的证据边界——」逐条走 §4：
    - ✅ 已验证：前视构造性防护、审批绑定、恢复语义、故障七步、τ_b 报告口径（全部有决策记录+实测）；
    - 🚧 留后续：群组消息面（留集成验收）、汇报模板 Jaccard 扩展位（条件纳入，见模板 §8）、W6 试验账本/DSR 字段；
    - ❌ 不声称：任何第 3/4 档宣称。
12. **收尾台词（第 1–2 档合规示范）**：「本次交付的是：**流程可靠、证据完整的历史回测与原型演示**——每个数字可复跑、每条结论可回源。」
