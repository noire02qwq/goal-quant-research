## 摘要（中文译文）

挖掘新的 alpha（即有效的交易信号或因子）是量化投资研究中最重要的任务之一。传统的 alpha 挖掘方法——无论是人工合成因子，还是算法式的因子挖掘（例如用遗传编程进行搜索）——都有其固有局限，尤其在落实量化研究员的想法时更是如此。

本工作通过引入人机交互，提出一种新的 alpha 挖掘范式；并借助大语言模型的力量，给出一个基于提示工程（prompt engineering）的算法框架来实现这一范式。我们进一步开发了 Alpha-GPT，一个交互式 alpha 挖掘系统框架：它以启发式的方式「理解」量化研究员的想法，并输出有创造性、有洞察力且有效的 alpha。我们通过多组 alpha 挖掘实验验证了 Alpha-GPT 的有效性与优势。
