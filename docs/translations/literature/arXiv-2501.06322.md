## 摘要（中文译文）

随着大语言模型（LLM）的近期进展，Agentic AI 在现实应用中表现亮眼，正走向由多个 LLM 智能体协同感知、学习、推理与行动的形态。这类 LLM 多智能体系统（MAS）让一组智能体得以协调配合、大规模地共同解决复杂任务，从彼此孤立的模型转向以协作为中心的方法。

本工作对 MAS 的协作机制做了全面综述，并提出一个可扩展的框架以指导后续研究。该框架从几个关键维度刻画协作机制：参与者（涉及哪些智能体）、类型（合作、竞争或竞合）、结构（点对点、集中式或分布式）、策略（基于角色或基于模型），以及协调协议。通过对现有方法的梳理，我们的发现可作为基础，帮助厘清并推动 LLM MAS 走向更智能、更协作的方案，以应对复杂的真实用例。

此外，我们还考察了 MAS 在多个领域的应用，包括 5G/6G 网络、Industry 5.0、问答以及社会文化场景，显示其采用日益广泛、影响不断扩展。最后，我们总结了 MAS 走向人工集体智能过程中的关键经验、开放挑战与潜在研究方向。
