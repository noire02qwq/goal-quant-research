## 摘要

大语言模型在各类基准上表现强劲——从知识问答、数学推理到 web 智能体任务——但这些测试都发生在静态环境中，缺少真实的动态与不确定性。因此，它们评估的是孤立的推理或问题求解能力，而不是不确定性下的决策能力。为此，我们提出 LiveTradeBench：一个用于在真实且不断演化的市场中评估 LLM 智能体的实时交易环境。

LiveTradeBench 遵循三条设计原则。其一，市场价格与新闻的实时数据流：既摆脱了对离线回测的依赖、防止信息泄漏，也能捕捉真实的不确定性。其二，投资组合抽象：把控制从单资产操作扩展到多资产配置，整合风险管理与跨资产推理。其三，跨市场评估：覆盖结构上截然不同的环境——美国股票与 Polymarket 预测市场——二者在波动性、流动性与信息流上各不相同。

在每一步，智能体观察价格、新闻与自身持仓，然后输出在风险与收益之间取得平衡的百分比配置。我们用 LiveTradeBench 对来自多个系列的 21 个 LLM 做了 50 天的实盘评估。结果显示：（1）LMArena 分数高并不意味着交易结果更好；（2）模型呈现出不同的组合风格，反映出各自的风险偏好与推理动态；（3）部分 LLM 能有效利用实时信号来调整决策。这些发现暴露出静态评估与真实世界能力之间的差距，也说明有必要用基准来检验实时不确定性下的序贯决策与一致性。
