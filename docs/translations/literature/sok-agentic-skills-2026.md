## 摘要

智能体系统越来越依赖可复用的程序性能力（即 agentic skills）来可靠地执行长时程工作流。这类能力是可调用的模块：它们把程序性知识与显式的适用条件、执行策略、终止判据以及可复用接口打包在一起。与一次性计划或原子化的工具调用不同，技能可以跨任务运行，而且往往表现良好。

本文描绘了技能层的完整生命周期——发现、练习、蒸馏、存储、组合、评估与更新——并提出两套互补的分类法。第一套是系统层面的**七种设计模式**，刻画技能在实践中如何被打包与执行：从元数据驱动的渐进式披露、可执行代码技能，到自演化库与市场分发。第二套是正交的「表示 × 范围」分类法，描述技能**是什么**（自然语言、代码、策略、混合）以及它们运行于哪些环境（Web、操作系统、软件工程、机器人）。

我们分析了基于技能的智能体在安全与治理上的影响，涵盖供应链风险、经由技能载荷的提示注入，以及分信任等级的执行，并以 ClawHavoc 战役为案例：近 1,200 个恶意技能渗入一个主流智能体市场，大规模窃取 API 密钥、加密货币钱包与浏览器凭据。我们还综述了确定性的评估方法，其依据是近期的基准证据——精心整理过的技能能显著提升智能体成功率，而自动生成的技能可能反而降低成功率。最后，我们提出面向真实世界自主智能体的鲁棒、可验证、可认证技能所面临的开放挑战。
