## 摘要

LLM 交易 agent 的回测常常假设每笔订单都以收盘价成交。我们追问：这一选择是只改变报告的收益，还是也会改变 agent 之间的排序。五个提示词驱动的 LLM 信号策略与七个经典基线在同一批合成价格路径上交易，覆盖六种执行设定，从近理想成交一直到延迟、点差、参与率与市场冲击压力。主实验包含 2,462 次运行，决策频率配对、市场路径成对。在压缩的两资产面板上，高波动模式下近理想执行与默认压力执行之间排名的一致性降到 Kendall 𝜏𝑏 = 0.21，而平静模式下为 0.82。种子 bootstrap 区间 [0.00, 0.52] 与 [0.48, 0.94] 都很宽且相互重叠。在固定的 11 策略面板上，一致性从两资产的 0.24 升到十资产的 0.85；两资产的点估计与我们测试过的更宽设定差异显著。排名变化与换手率相关，而与买入持有的比较还取决于该锚如何初始化。本实验不比较 LLM 交易技巧。它表明：在短视野下，一种执行惯例可以成为该基准的头条结论。执行假设与排名稳定性应当与收益一同报告。

## 1 引言

LLM 交易 agent 常按回测收益排名。模型观察市场状态、提出一笔交易，并在事后得到一个评分。然而在提议与评分之间，回测器必须决定这笔交易何时、如何成交。许多研究直接假设按观察到的收盘价全部成交，且不讨论这一选择。

如果执行成本对每个策略的影响大致相同，这种简化便无伤大雅。但我们没有多少理由这样假设。订单要穿过点差、要等待、只部分成交，或者推动价格；不同策略的交易频率也不同。市场微观结构研究几十年来一直在研究这些效应 [1, 4, 9]，实践中的回测也常规地调整其成本假设。LLM-agent 评估却很少报告其排名能否经受同样的检验。

为了测量这一效应，十二个策略在六种执行设定下交易完全相同的市场路径。其中五个从 LLM 获取信号，七个是经典基线。市场路径与决策频率共享，因此这组比较只改变执行，而不改变最初展示给 agent 的信息。

最大的排名变化出现在一个只有两种资产的短、高波动实验中。这也正是领先策略最难区分的设定。更宽的资产池有一致性更高的点估计，且不确定性很大。这一发现关乎基准本身，而不是哪类策略交易得更好。这里「LLM agent」指一个提示词驱动的信号策略：模型为每个资产产生一个有界的信号，而组合构建、风险控制和执行是共享的。带工具、角色或持久记忆的 agent 不在主实验范围内（Section 7）。

本文的贡献是一次经验性的成对比较：固定市场路径与决策时点，只改变执行。我们追踪低一致性的那个案例，经过换手率、资产池规模、视野、锚初始化和一次真实价格核验。运行级结果与用于生成表格和图表的代码均已公开（Section 8）。

## 2 相关工作

金融语言模型 [19, 23] 以及 TradingAgents [20]、FinRobot [24]、FinMem [25] 等 agent 框架，已使回测交易成为常见的评估任务。由于这些系统在工具使用、记忆和角色化推理上各不相同，我们只把模型当作有界信号的来源，并把下游的组合与执行栈固定不变。

执行本身是一个古老得多的文献。关于知情交易、最优拆单、经验冲击和订单簿瞬态效应的研究解释了为什么成本既取决于订单也取决于市场 [1, 2, 4, 7, 9, 17]。可配置的交易成本在 FinRL-Meta [13] 等交易环境中也是标准配置。实际交易成本可能与简单估计相差甚远，并会改变哪些策略看起来可行 [5, 6]。

最接近的先例是关于基准敏感性的工作。回测选择与多重检验会产生不稳定的结论 [3, 8, 14]。LLM 评估同样对提示词措辞和协议选择敏感 [11, 15, 18]，多步 agent 基准则引入了对协议与状态的依赖 [12]。金融 LLM 综述与更广泛的基准汇总了模型表现 [10, 16, 21]。较少受到关注的是：一个交易排行榜能否在执行假设改变后存活下来。这正是本文研究的问题。

## 3 执行模型

实验使用 TradeArena 测试平台 [22]。在每个决策点，框架把信号转换为目标权重，施加风险闸门，生成订单，模拟成交，并更新组合。表 1 总结了六种执行设定。E0 采用立即、完全的成交。E1 加入延迟、参与率、冲击以及部分成交或拒绝的可能。每一个单轴 E2 设定从 E1 出发只改一个参数；harsh 设定同时改变三个命名轴和市场冲击。

表 1：执行设定。Latency 以 bar 计；参与率上限（Cap）是单个 bar 成交量的最大占比；Spread 是完整报价点差（基点）；𝜅 是线性冲击系数。每种设定都收取 1 bp 佣金和 2 bps 基础滑点。E1 和 E2 还包含 bar 内波动项。（原文第 2 页）

| 设定 | Latency | Cap | Spread | 𝜅 |
|---|---|---|---|---|
| E0 near-ideal | 0 | – | 0 | 0.00 |
| E1 default | 1 | 5% | 0 | 0.15 |
| E2 spread | 1 | 5% | 20 | 0.15 |
| E2 latency | 3 | 5% | 0 | 0.15 |
| E2 participation | 1 | 1% | 0 | 0.15 |
| E2 harsh | 3 | 1% | 20 | 0.30 |

在合成路径上，一笔订单得到

$$q_{\text{fill}} = \min(|q|, \rho V_t)$$

股，其中 𝜌 是参与率上限，$V_t$ 是该 bar 的成交量。其执行价格为

$$p_t^{\text{exec}} = p_t^{\text{close}} \left(1 \pm \frac{\text{spread}}{2} + s_0 + \kappa \frac{q_{\text{fill}}}{V_t} + \lambda \nu_t\right)$$

买入取正号，卖出取负号。我们取 $s_0 = 2$ bps、𝜆 = 0.1，𝜅 在 E1 为 0.15、在 harsh 设定为 0.30，其中 $\nu_t = (\text{high}_t - \text{low}_t)/p_t^{\text{close}}$。报价点差按半点差在两侧各收取一次，1 bp 佣金另按名义金额收取。任何超出参与率上限的数量直接取消，而非排队。延迟 ℓ 把订单移到 bar $t + \ell$。

译注：该公式的 PDF 文本提取有部分乱码，此处按上下文与符号说明重建；原文此处的排版无法完整提取。

每次运行以 $100,000 现金、价格约 $100 开始。带种子的收益生成器组合了趋势、季节、宏观、新闻和特质项。高波动模式把波动率、趋势和宏观分量分别缩放 2.25、0.65 和 1.4；jump/tail 模式使用 Student-𝑡 3 冲击与跳跃。成交量约为 $10^6 (1 + 10|\varepsilon_t|)$ 股。

这些设定是压力测试，不是对特定市场交易成本的估计。合成的成交量尺度使参与率上限对 $100,000 的账户基本不起约束。我们在 $30M 上重复该确定性实验，此时上限生效（Section 5.7），并单独扫描参数（Section 5.8）。所有策略使用同一个风险闸门：单名 0.35 上限、总敞口 1.0、以及 −20% 时触发的五 bar 回撤熔断开关。

## 4 实验设置

**Agent。** 七个确定性基线是：买入持有、信号加权配置、朴素动量、五 bar 均值回归、12 bar 风险平价、24 bar 最小方差，以及一个带种子的随机分配器。它们都是只做多的。除买入持有外，每步都再平衡。单名权重上限 0.35，最小方差除外——它用 0.08，以防近乎奇异的两资产协方差估计把组合集中到单一资产。在两资产的买入持有组合中，每个资产各得 35%，其余留在现金。

五个 LLM 策略使用四个提供商路由别名（gpt-5.5、gemini-3.1-pro、claude-opus-4.7 和 glm-5）和一个直连 API 模型（deepseek-v4-pro）。路由别名并不指向稳定的后端检查点。我们把它们当作采集期间可得接口的观测，而不是对具名模型版本的可复现测量。直连 API 同样使用无日期的标识符，因此也不能确立固定的后端版本。

每个 LLM 收到结构化 JSON 提示，其中包含近期 OHLCV bar、组合状态和风险反馈。它为每个资产返回一个 [−1, 1] 内的信号，而不是目标权重。一个共享的策略把这些信号转换成权重，之后才运行共同的风险与执行层。提示中不点名执行设定，也不暴露其参数。因此第一个决策在所有设定下完全相同。后续决策可能不同，因为此前的成交已经改变了组合状态。

响应按 provider:model:sha256(prompt) 缓存，提示中的时间戳已移除。提供商缓存不重新分发。公开发布包含论文所用的运行级数据及这些文件的哈希。

**市场模式。** 一个带种子的模拟器生成平静趋势、高波动和跳跃/尾部路径。生成的路径不可能逐字出现在模型的训练数据中，这降低了直接的测试集记忆。Section 5.9 在真实 OHLCV 数据上增加一次确定性核验；我们不用该历史窗口对 LLM 表现下结论。

**重复与配对。** 每个（模式，层级，agent）单元使用十个种子。一个种子固定市场路径，每个 agent 在该路径上于每个执行层级做 12 次决策。主矩阵包含 12 × 3 × 6 × 10 = 2,160 次运行。另有 302 次 LLM 运行支持采样方差核验，合计 2,462 条记录、14,424 次提供商调用。稳健性实验单独计数。我们对每次运行计算 Sharpe，然后在单元内对种子取平均。

**统计量。** 在单元内，策略按跨种子的平均 Sharpe 排名。运行级 Sharpe 是逐步权益收益的均值除以其标准差，再乘以 $\sqrt{252}$。12 步窗口会把这些数值放大，因此只能在实验内部比较。我们用 Kendall 𝜏𝑏 和 top-3 Jaccard 重叠度量执行层级之间的一致性。

对摩擦脆弱性，我们把每个策略 $a$ 与买入持有 $b$ 比较，使用按种子的双重差分 $(R_{a,s}^{E0} - R_{a,s}^{L}) - (R_{b,s}^{E0} - R_{b,s}^{L})$。正值意味着 $a$ 在移动到压力层级 $L$ 时比锚损失更多。我们汇总 30 个配对的模式-种子差值，使用双侧符号翻转检验：取值不超过 16 个时精确枚举，否则用 2,000 次 Monte Carlo 分配并做加一修正。Benjamini–Hochberg 校正覆盖 E1 与 harsh 设定上声明的单一族——11 个非锚 agent。其他执行层级与按模式的摘要是探索性的。只有三个模式块，后者无法支持模式级的显著性主张。重复的提供商样本在比较前先在种子内取平均。

## 5 结果

### 5.1 执行假设改变排名

图 1 把 E0 排名与每个压力排名比较。平静面板相当稳定，𝜏𝑏 在 0.73 到 0.85 之间。jump/tail 面板较不稳定（0.30–0.58）。最大的变化出现在高波动的 E0–E1 比较：𝜏𝑏 = 0.21，种子 bootstrap 95% CI 为 [0.00, 0.52]；平静模式的对应估计为 0.82（[0.48, 0.94]）。这些区间很宽且相互重叠。在每一个高波动压力设定下，E0 与压力执行的前三名都只有一个策略相同（Jaccard 0.2）。

名义上更严苛的设定并不总是产生更大的排名变化。在高波动模式内，E1 给出 𝜏𝑏 = 0.21，1% 参与率设定给出 0.27。在该账户规模下这两个设定几乎等价；微小差异来自提供商重采样而非上限生效（Section 5.7）。组合的 harsh 设定给出 0.52，而单轴的 latency 与 spread 设定分别给出 0.58 和 0.39。只有当我们沿一个从流动到不流动的公共参数网格变化时，才出现单调模式（Section 5.8）。

### 5.2 为什么 Sharpe 比总收益动得更多

对一次运行，Sharpe 为 $S = \sqrt{252}\, \bar{r}/s_r$，由 12 个组合收益计算。执行改变的是序列 $r_1, \ldots, r_{12}$：延迟把敞口从一个 bar 移到另一个，部分成交减少敞口，而交易成本在成交发生时扣除。总收益大体上只汇总复利后的终点。Sharpe 同时使用路径的均值与离散度，因此同一次成交可能影响它的分子、分母，或两者。这在高波动路径上最显著——把敞口移动一个 bar 就会改变组合持有的是哪一段收益。

这种差异在排名中可见。对总收益，E0–E1 的 𝜏𝑏 在平静、高波动、jump/tail 市场中分别是 0.97/0.70/0.61；对 Sharpe 则是 0.82/0.21/0.52。$\sqrt{252}$ 年化因子不是原因：它对所有策略相同，不会改变顺序。不确定的部分是 $s_r$，此处仅由 12 个收益估计。一次改变其中一两个收益的成交，对终端财富可能影响很小，却会明显改变样本波动率。当几个策略的分数本来就相近时，这种差别就很重要。

这一区分改变了结果的读法。总收益记录组合最终到达哪里；Sharpe 还记录到达那里所走的路径。我们用 Sharpe 作为风险调整后的排名指标，但收益排名清楚表明：最大的变化来自在短窗口上估计风险，而不是仅来自终点表现。

### 5.3 哪些策略在移动

表 2 显示高波动的变化来自哪里。在 E0 下，前五名全部是经典策略。在 E1 下，每个 LLM 策略都上升二到七位，其中四个进入前五。两个最弱的经典策略仍在底部。换手率有差异，但并不干净：经典策略平均 18–20 次 E1 成交，LLM 策略平均 15–18 次，成交率相近（0.80–0.86）。置信区间大幅重叠。清楚变化的是顺序；这张表无法区分两组的交易能力。

有些 LLM 策略从 E0 到 E1 甚至获得少量 Sharpe 和总收益的提升；deepseek-v4-pro 的总收益从 +0.050 升到 +0.076。这不必反映更好的决策。在这个短实验中，频繁再平衡本就代价不菲，而 E1 压制了其中一部分交易。一个换手率更低的策略即使在执行整体变得不利时，也可能在相对意义上上升。

### 5.4 换手率分组内的排名变化

我们用实现的 E1 换手率把策略分成三分位，并在每组内重算 E0–E1 一致性。组内平均 𝜏𝑏 为 0.63。在高波动模式下，三个三分位都给出 0.67，而完整面板给出 0.21。完整面板的变动大部分发生在换手率组之间，不过换手率相近的策略仍会重排。这是一次描述性核验：每个三分位只有四个策略，且 E1 换手率本身就是实验的产物。

我们还加入一个成本感知的风险平价基线：只有当权重漂移超过 0.05 才交易。它的平均 E1 换手从 20–21 次成交降到 14–17 次。它在高波动 E0 下排名第一、E1 下排名第六。纳入该策略后，三个模式的 E0–E1 𝜏𝑏 分别为 0.69、0.23 和 0.51。高波动与 jump/tail 的值仍接近 0.21 和 0.52；平静值从 0.82 降到 0.69。加入这个更不活跃的基线并没有消除低一致性案例，尽管该扩展在每个单元格只有一个提供商样本。

### 5.5 排行榜压缩

重排的幅度与领先者聚集的紧密程度相关。在 15 个「模式 × 压力」单元格中，压力层级下第 1 名与第 5 名的 Sharpe 差距与 E0 一致性相关系数为 𝑟 = 0.75。前五差距低于 0.6 的每个单元格都有 𝜏𝑏 ≤ 0.42；平静单元格的差距为 1.4–2.2、𝜏𝑏 > 0.72。这 15 个单元格聚集在三个模式内，因此我们把该相关当作描述而非检验。它与高波动表中可见的现象一致：领先者的置信区间重叠。

图 2a 在每个资产池规模上保持同样的 11 个策略：七个经典策略、deepseek-v4-pro 和三个路由策略。E0–E1 的 𝜏𝑏 从两资产的 0.24 升到三资产和五资产的 0.71，十资产的 0.85。四个区间都很宽且重叠。我们把这条曲线读作对两资产估计的边界，而不是资产池规模单调效应的证据。

### 5.6 买入持有锚

双重差分比较问的是另一个问题：加入摩擦后，一个策略是否比买入持有损失更多收益。在 E1 下，没有策略比锚更脆弱；deepseek-v4-pro 的脆弱性低 2.5 个百分点（𝑞 = 0.029）。在 harsh 设定下所有点估计为负：deepseek-v4-pro（−4.0 点）与均值回归（−4.5 点）的 𝑞 = 0.005。符号跨模式一致，但三个模式块不足以支持单独的模式级检验。

锚从现金起步，因此它测得的损失包含建立初始头寸的成本。当锚从目标组合已经就位起步时，warm 减 cold 的收益差在 E0 为零，在 harsh 设定平均为 0.025，jump/tail 中达到 0.046。因此锚表面上的脆弱性有一部分是初始化效应。完整面板的排名比较不使用该锚。

我们在独立误差、种子内方差相同的假设下估计采样方差。若 $𝑊$ 是有重复种子的平均样本方差，$𝑉$ 是全部 $𝑆$ 个种子均值的样本方差，种子 $s$ 有 $n_s$ 个样本，则种子间估计为 $B = \max\{0,\; V - W\, S^{-1} \sum_{s=1}^{S} (n_s - 1)\}$。估计份额为 $𝑊/(B + 𝑊)$；截断与有限的重复次数使它不确定。我们的摘要使用 14 个「十个种子各三次采样」的单元格：平均份额约 17%（范围从低于 0.001 到 0.53），头条比较的高波动 E1 单元格为 0.14。另有四个重复不均的单元格出现在发布表中但被排除在本摘要之外；其中两个仅由一个重复种子估计 $𝑊$。样本取平均使 DiD 估计至多变化 0.4 个百分点。只有 deepseek-v4-pro 的 E1 比较在取平均后越过阈值，因此我们把该结果视为边缘性结果。

### 5.7 哪些摩擦真正生效

在 $100,000 的账户规模下，单个资产的头寸至多约 350 股，而合成的 bar 成交量约为一百万股。因此 5% 和 1% 的参与率上限分别允许约 50,000 和 10,000 股。没有任何确定性成交触及这两个上限，实现的参与率保持在 0.1% 以下，线性冲击远低于一个基点。12 个策略中有 11 个在两个上限设定下产生完全相同的记录。剩余差异在从固定响应缓存重放直连模型后消失，确认它来自重采样。

E1 的成交率对 LLM 与经典策略都在 0.78 到 0.86 之间；harsh 设定下降到 0.37–0.54，主因是三 bar 延迟。相近的成交率不意味着相近的排名变化。在高波动下，延迟把成交率降到 0.48 却留下 𝜏𝑏 = 0.58；E1 让成交率保持在 0.83 附近却给出 𝜏𝑏 = 0.21。spread 设定滑点最大，给出 𝜏𝑏 = 0.39。重要的是成本惩罚了哪些策略，尤其是它们再平衡的频率和幅度。

与此一致，把 E0–E1 收益损失或排名移动对策略自身成交率与滑点成本做回归，得到 $𝑅^2 < 0.02$（每个系数 $p > 0.5$，𝑛 = 36 个单元格）。这些诊断无法为排行榜提供可靠的事后修正。

最后，我们在 $30M 上重复确定性实验。参与率上限此时在 33–95% 的成交上生效，但高波动的 E0–E1 一致性在两个账户规模下仍为 𝜏𝑏 = 0.81。对这组策略而言，单笔成本与换手率比上限是否生效更重要。

### 5.8 参数敏感性

在高波动模式下，我们还沿一个从流动到不流动的网格同时改变冲击、参与率与延迟。流动设定（冲击 0.05、10% 参与率、无延迟）使确定性排名不变（𝜏𝑏 = 1.0）；典型权益设定给出 0.81，不流动端（冲击 0.30、1% 参与率、三 bar 延迟）给出 0.43。与异质的 E2 设定不同，这个受控网格产生了单调模式。

### 5.9 真实价格稳健性

我们在真实 Yahoo OHLCV 上用同样的执行设定运行七个确定性策略。数据覆盖 2022 年利率回撤期与 2025 年跨资产窗口中的八个流动 ETF 与比特币，使用周频复权收盘、12 次决策和三个偏移。两个窗口的 E0 到压力的 𝜏𝑏 都在 0.71 到 0.90 之间。前三名只在 spread 设定下改变（Jaccard 0.5；否则为 1.0）。这比合成的两资产结果温和，但表明确定性排名在经验价格与成交量路径上同样会移动。这不是对 LLM 策略的历史检验。

## 6 讨论

这里的实际要点比「执行很重要」这一熟语更窄。在高波动的合成单元格中，一个模拟器选择就把表面上的领先者从经典策略换成了 LLM 策略。区间重叠，因此两种排序都不能证明某一组更好。相反，这组比较表明：一个基准可以把一个实现选择变成它的头条结论。

一个有用的评估应当说明其成交规则、成本、延迟、参与率限制、决策频率和锚的初始化。然后它应当至少在一个合理的替代设定下重跑整个面板，并报告排名一致性，而不只是收益变化。共享的市场路径与成对统计让这组比较更有信息量，运行级记录则让他人可以检查它。运行结束后再估计成本并不等价。策略自身的成交率与滑点几乎解释不了它的排名移动（𝑅² < 0.02）。这种移动取决于同一摩擦如何作用于全体策略。因此排行榜应当重跑，而不是逐个分数做修正。

## 7 局限

我们最强的结果也是最窄的。头条面板只有两种资产、12 次决策，且若干策略的 Sharpe 估计相近。在固定的 11 策略资产池实验中，高波动的 E0–E1 𝜏𝑏 从两资产的 0.24 升到十资产的 0.85。一个同种子的确定性十资产实验在五个压力设定下给出 0.79–0.93。0.21 是这个压缩面板的结果，不是通用的效应量。我们排除了一个提供商支持的十资产 E2 运行，因为它的 E0 与 E2 种子不匹配；该规模下完全配对的 LLM 阶梯仍有待运行。

短视野使 Sharpe 与终局处理都很嘈杂。挂单在 12 次决策后被取消，因此延迟 ℓ 可能删失多达 ℓ/12 的迟到订单。我们没有运行分离该选择所需的配对「成交 vs 取消」比较。高波动与平静的 E0–E1 一致性种子 bootstrap 区间很宽且略有重叠。

更长的视野给出混合模式（图 2b）。确定性面板在 12 到 120 步之间保持在 0.71 到 0.91，而直连面板非单调且不精确。仍可得的路由子集在 30、60、120 步分别给出 0.94、0.56、0.83。重排可以复发，但极端的 0.21 估计属于一个短而压缩的面板。

LLM 实验是闭环的。一旦成交不同，模型看到的组合状态就不同，可能改变下一个信号。确定性策略提供了一次机械比较，因为它们的目标跨执行层级相同，且回撤开关从未触发（0/840 步）。对直连 LLM 面板，把 E0 的决策在 E1 下重放给出 𝜏𝑏 = 0.56，而让策略重新决策为 0.44。机械执行本身就会改变排名。额外的差异与反馈及新的提供商采样一致，但这两个 𝜏𝑏 值无法分离二者的贡献。

五个头条 LLM 策略中有四个是路由的。没有一个托管 API 标识符把观测绑定到不可变的后端版本。冻结的记录保存了被分析的快照，但那些响应无法逐字节再次采集。结论适用于采集期间观察到的提供商接口和提示词驱动的信号策略，不适用于稳定的模型版本，也不适用于带工具、反思和多角色的更丰富 agent。

最后，合成路径支持配对、避免训练数据污染，但不能确立实盘表现。真实 OHLCV 实验只覆盖九个 ETF 与加密品种上的确定性策略。在同一历史窗口上运行 LLM 会引入可能的记忆混淆。训练截止后的前瞻性测试与报价级成交重放仍在本研究之外。

## 8 可复现性

论文所用的代码、执行设定、种子、运行级结果和分析脚本见 https://github.com/weich97/execution-assumptions-rankings 。发布内容包含每个「模式 × 层级」的排行榜、bootstrap 区间，以及每个策略的换手率、成交率和滑点成本。表格与图表可以从冻结记录重建，无需 API 调用；确定性实验可以从头重跑。新的 LLM 采集需要提供商访问权；原始提供商响应与逐步轨迹不包含在内。

## 9 结论

我们追问：当 agent、市场路径和绩效指标保持固定而执行改变时，一个交易 agent 排行榜能否存活。在压缩的两资产面板上，答案常常是不能；更宽资产池的核验有更高的一致性。这个结果关乎基准测量什么，而不关乎哪类策略交易得更好。执行规则属于基准规范的一部分，应当在把微小的排名差异解读为 agent 质量差异之前先行变动它们。
