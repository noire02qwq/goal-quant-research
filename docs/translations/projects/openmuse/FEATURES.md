原生端和 web 端的 agent 核心在本地运行。这份清单描述当前实现与尚待完成的扩展。真实提供方和可选基础设施需要单独配置与验证。

## 已实现的覆盖范围

| 领域 | 当前实现 | 尚待扩展 |
| --- | --- | --- |
| Chat / 委派工作 | 原生 CopilotKit 聊天；直接读取邮件与有时间界限的主日历；可持久化任务与已确认的结果 | 真实模型/提供方的验收测试 |
| Ideas / 个人上下文 | 带出处的邮件/目标规则；接受/编辑/忽略；身份信息；可编辑、可遗忘的记忆 | 更广泛的、由模型生成的跨连接器建议 |
| Goals / Tracking | 里程碑、周期性监控、观察结果、重试/退避、暂停与取消 | 自适应长期规划与日历驱动的提醒 |
| Browser | 常驻 Chromium、公开页面读取、快照、控制台接管、PDF 下载 | 自动化的交互式预订，以及按人编排的虚拟机 |
| Linux computer | 非 root Docker 容器；有界的 bash/Python/Node/git 命令；保存的输出与退出回执；持久工作区文件；文本编辑；PDF 导入/导出 | 交互式终端、桌面应用、受控出站流量、磁盘配额与更强的虚拟机隔离 |
| Gmail / Calendar | Google OAuth；完整会话；保存的草稿；带审阅版本的日历/事件 CRUD | 真实 Google 验收、重复规则编辑、其他连接器 |
| PDF 任务 | 可持久化的导入、带类型的输入请求、填好副本的预览、经审阅的回复、回执 | OCR/扫描表单以及更多 PDF 字段类型 |
| 生成结果 | 计划/报告/对比、财务 CSV 指标，以及私有 Linux 工作区里的脚本 | 托管的工具安装/版本管理，以及图像/音频生成 |
| 通知 | 可持久化的应用内收件箱、带出处链接的变更告警、重启后对账 | APNs/FCM/设备推送投递 |
| 连接器 | 可检索的能力/状态目录、Google 连接、浏览器 worker | Plaid、健康、Instagram、WhatsApp 及合作方 API |
| OpenBot | 默认禁用的适配器，带固定版本的协议/身份测试 | 实时会话桥接、常规例程与计算机后端接线 |

Linux computer 在服务端配置完成前是禁用的，且没有网络访问。它是一个带持久化 `/workspace` 的单所有者容器，与浏览器 worker 分离；见[计算机设置与限制](COMPUTER.md)。它既不是图形桌面，也不是完整的操作系统虚拟机。

模型聊天可以在明确的时间范围内读取已连接的主日历，范围最长 366 天。缺失日期或时区需要澄清。一次回复最多使用 20 个事件及有界的事件文本；部分结果和连接失败都会如实报告。全天事件保留其日历时区和不含尾日的结束日期。日历变更仍需经过操作审阅。示例 agent 的固定回复并不提供这个模型工具。

实现与验证细节见 [VERIFICATION.md](VERIFICATION.md)。计划中的扩展不代表当前已支持。优先级记录在[路线图](../ROADMAP.md)里。
