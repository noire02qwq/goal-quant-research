简要概括：Rakazo 是一个开源、自托管的 AI 智能体项目，定位为 Grok Bot 等托管助手的"你真正拥有"的开源替代——给每个 bot 一份工作，从任意设备跟进。它提供网页版、Electron 桌面应用和 iOS/Android 客户端，bot 各自拥有对话、记忆、例行任务（routines）与历史，共享 Team Computer 或使用 Private Computer。它可接入自己的模型（Claude、ChatGPT、OpenRouter、Grok、Ollama、LM Studio 等）和计算环境提供商，也能通过 Slack、iMessage、WhatsApp、Telegram 等渠道收发消息。项目采用 Apache-2.0 许可，README 还包含与其他产品的对比、技术栈、Railway 部署与快速开始说明。
